Balls Bouncing demo

In no way perfect, as it definitely looses energy over time due to faulty physics interactions, we can call it air resistance. I wrote the simulation just to test coding for the web for the first time. The simulation is written in C using Web Assembly, using a simple graphics library called olive.c as the backend.

Julia Set Demo
